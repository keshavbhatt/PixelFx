  1. Compress only is a mode of the Batch page: the same list, the same Add and drop, no recipe. It is free for any number of files (PLAN D26). Everything runs inside PixelFx; no external tools (ADR-002).
  2. Per format: JPEG lossless (smaller encoding, identical pixels) or a target quality; PNG lossless or fewer colours with a quality floor. Other formats are re-encoded only when the result is smaller.
  3. Each row: before and after size, a bar for the new size, the saving. "No change" when the file was already as small as it gets, and the original is kept (setting, on by default).
  4. Selecting a row shows the same spot of before and after at 100% so a lossy setting can be checked by eye; arrow keys move through the rows.
  5. Run again with these settings re-processes the same list after a change, as PixelBatch users are used to. Save into a folder by default; Replace the originals asks once.
  6. Totals: saved size and share, time taken, Show in folder.
