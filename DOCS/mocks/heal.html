  1. Heal mode (R) for blemishes, dust spots and small objects. Click: a circle the size of the brush is healed from a patch PixelFx picks nearby with matching texture and light (solid outline = healed area, hollow = source).
  2. Every spot is a setting, not pixels: select it to resize it, drag the hollow source circle to choose another patch, delete it any time; spots are in history and in the photo's sidecar. Spots are never part of presets or batch (they belong to one photo).
  3. Brush mode paints a stroke for longer marks (wires, scratches, a stray hair) and heals along it.
  4. Reveal dust shows a high-contrast view where sensor dust and specks stand out, a known pain on skies.
  5. The brush cursor shows its size on the photo; size is relative to the photo, so it fits at any zoom.
