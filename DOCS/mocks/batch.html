  1. Batch applies one recipe to any number of photos and writes new files. Add photos or folders (with subfolders), or drop them.
  2. The recipe is a look or preset (several can be stacked), or the settings of a photo open in the editor. Optional per-photo Auto enhance.
  3. Resize and Save as use the same options as the Export sheet; the originals are never touched unless Overwrite is picked, which asks once.
  4. Save as batch recipe stores the whole page (recipe, size, format, folder, name) so a repeated job is one click; recipes also run from the command line (pixelfx --batch recipe.pfxbatch *.jpg).
  5. Runs on all CPU cores with a memory cap, in the background: the editor stays usable and the window title shows progress.
